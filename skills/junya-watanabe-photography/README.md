# JunyaWatanabe / jungraphy_ 摄影 Skill

一份用于摄影策划、图像生成提示词、修图方向和照片分析的中文摄影工作流。它基于日本摄影师 Junya Watanabe（Instagram：[@jungraphy_](https://www.instagram.com/jungraphy_/)）的公开资料与作品研究，将视觉特征转化为可执行的创作建议。

这里指的是东京摄影师，不是同名时装设计师。本 Skill 为独立研究整理，非官方、无关联，未获得摄影师授权。

## 适合做什么

- **摄影策划**：设计主题、场景、人物动作、服装、镜位、光线、分镜和组照顺序。
- **生成提示词**：把抽象的风格要求转成具体场景、表面、构图、色彩和情绪描述。
- **修图方向**：提出曝光层次、局部颜色、反射、建筑校正和主体引导建议。
- **照片分析**：按构图、光线、色调、镜头感、人物姿态、场景、服装、后期、叙事九个维度评价照片。

核心不只是“霓虹 + 赛博朋克”，而是雨、人工光、城市表面和时间如何共同改变城市：湿路面、玻璃、金属、伞与衣料之间的光线关系，具体的街道空间，以及人物在其中留下的尺度和情绪。

## 可直接复制的使用示例

### 1. 摄影策划

```text
使用 $junya-watanabe-photography。
我要在上海拍一组雨后夜间城市照片，不照搬东京街景。
主题是“末班车之后”，一位人物，深色日常服装，拍摄时间 90 分钟。
请输出：一句创作命题、场景类型、8 张分镜、镜位与焦段意图、
人物动作、服装建议、后期方向、组照顺序，以及雨天安全注意事项。
具体地点与拍摄规则如需推荐，请先核验；无法核验时只给场所类型。
```

### 2. 图像生成提示词

```text
使用 $junya-watanabe-photography。
为“雨停后的便利店门口，一个撑透明伞的下班人”写一条完整英文图像提示词。
竖幅 3:4，真实摄影质感，人物占比小，强调路面和玻璃两种反射。
避免全局橙青滤镜、随机霓虹和过度辉光。
请附中文解释与避免项；最终提示词不使用摄影师姓名，不复刻具体作品。
```

这个请求默认交付提示词，不代表已经生成图片。如果希望直接出图，再明确说“请根据这个提示词生成图片”；是否能生成取决于当前环境的图像工具。

### 3. 分析自己的照片

先附上照片，再发送：

```text
使用 $junya-watanabe-photography 分析我上传的照片。
按九个维度逐项给出画面证据，区分可见事实、推断和无法判断。
总结三个相符点、两个偏离点，以及一个最值得优先调整的方向。
不要从成片猜测精确相机型号、焦距或调色参数。
```

### 4. 修图建议

```text
使用 $junya-watanabe-photography，为这张照片给出 Lightroom 修图方向。
保留人物身份、皮肤自然度、建筑结构和品牌文字，不替换画面内容。
按曝光层次、白平衡与局部颜色、反射、主体引导和输出锐化组织建议。
说明每一步想改变的视觉关系，不编造摄影师的官方预设或固定参数配方。
```

这会给出修图方案，不会自动操作 Lightroom 或保存修改后的照片。需要实际编辑时，请另行明确编辑要求，并提供可用的原图与编辑工具。

### 5. 环境人像 / 品牌策划

```text
使用 $junya-watanabe-photography，为一个城市通勤服装品牌设计环境人像系列。
地点为雨后车站周边，人物动作克制，服装必须清晰可读。
给出 6 张分镜、人物与场所的关系、光源安排、服装搭配和选片标准。
避免把所有画面都变成浅景深霓虹背景。
```

## 怎样提问更有效

尽量提供：**用途 + 地点或场景 + 主体 + 天气与时间 + 比例 + 限制 + 希望得到的交付**。

例如：“为品牌社交媒体拍摄 / 广州老街 / 一位通勤者 / 雨后傍晚 / 竖幅 4:5 / 两小时、不能额外布灯 / 需要 8 张分镜和后期建议”。没有明确的信息可以让 Codex 做合理假设，但应要求它标注假设。

## 使用边界

- 这是研究得到的创作框架，不是作者本人提供的教程、官方预设或器材参数。
- 支持原创创作与分析，不承诺精确复刻某张作品或作者的完整创作过程。
- 不包含摄影师作品图片，不将其作品打包再分发。
- 不把“城市雨夜”简化为固定滤镜；构图、空间、人物和叙事同样重要。
- 真实拍摄须考虑许可、路人隐私、交通和天气风险，不能为画面进入危险积水道路或雷暴环境。
- 涉及近期作品、店铺营业、地址或拍摄规则时，需要重新核验公开信息。
