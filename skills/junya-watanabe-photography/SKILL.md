# JunyaWatanabe / jungraphy_ 摄影

## 核心原则

- 将摄影师姓名请求翻译成可观察、可执行的视觉语言；生成提示词最终以特征描述为主，不依赖摄影师姓名。
- 将核心理解为“雨、人工光、城市表面与时间共同改变东京”，不要简化成泛化的“赛博朋克东京”。
- 区分三类内容：摄影师公开自述、公开作品中的重复观察、为当前任务提出的创作推断。不要把推断写成作者原话或固定规则。
- 默认使用用户的语言。先给可用成品，再简短说明关键选择与不确定性。
- 明确目标是 1992 年生、账号为 `@jungraphy_` 的东京摄影师；不要混入同名时装设计师或其他同名摄影网站。

## 读取资源

1. 每次任务先读取 [references/visual-language.md](references/visual-language.md)，再选择与任务相符的模式。
2. 需要策划、提示词、修图方案或风格分析时，读取 [references/workflows-and-templates.md](references/workflows-and-templates.md)。
3. 需要人物背景、出处、事实核验或更新研究时，读取 [references/sources.md](references/sources.md)。涉及“最新”“目前”或账号近期变化时，重新检索公开来源，不以本地研究笔记代替时效核验。

## 选择模式

| 模式 | 适用任务 | 保持的主轴 |
| --- | --- | --- |
| 雨夜城市 / 街头 | 城市风光、街拍、系列策划、生成提示词 | 湿表面、人工光、清晰空间、偶然人物、城市记录 |
| 环境人物 | 人像、艺人、品牌、角色或亚文化题材 | 人物身份与具体场所互相解释，姿态克制或有角色依据 |
| 物件 / 商业 | 产品、招牌、城市设施、酒店或品牌视觉 | 把物件当“城市角色”，用反射、局部光和表面细节建立叙事 |
| 照片分析 / 对比 | 单张、组照、参考图、选片或批评 | 逐项给证据，不以色彩相似度代替构图与叙事判断 |

## 执行工作流

### 分析照片

1. 先判断画面属于哪种模式，以及雨、夜、城市和人物是否真的参与叙事。
2. 按构图、光线、色调、镜头感、人物姿态、场景、服装、后期、叙事九项分析。
3. 每项标记为“可见”“较强推断”或“无法判断”；不要从成片反推精确相机、焦距、HSL 数值或作者意图。
4. 总结最强的三个相符点、两个偏离点和一个可执行改进方向。

### 策划拍摄

1. 明确用途、地点、主体、交付比例、真实拍摄限制和风险；缺失信息不影响方向时直接做合理假设并标注。具体场所的存续、地址、营业时间和拍摄规则属于时效信息，先联网核验；无法核验时只写“未核验候选”或场所类型。
2. 先写一句原创命题，再设计场所、天气、人物与光线如何共同证明它。
3. 按“建立空间—发现细节—引入人物—制造反射—收束余韵”组织组照，不要只列同一种霓虹街景。
4. 给出镜位、焦段范围、景深或快门意图、光源、人物动作和必要道具；把技术选择写成画面目的而非器材清单。
5. 单列天气、交通、许可、路人隐私、器材防护和撤离条件。不要鼓励在雷暴、台风、积水道路或能见度危险的环境中拍摄。
6. 给出后期方向与选片逻辑，不编造“官方预设”。

### 编写图像生成提示词

1. 将“像 Junya Watanabe / jungraphy_”拆成具体的场景、表面、构图、光源、镜头、色彩关系、人物行为与情绪。
2. 设计原创主体和原创空间关系，不复刻某一公开作品的独特构图、人物或可识别细节。
3. 输出一条完整的无姓名主提示词，并附简短的避免项；只在用户需要时提供克制、沉浸、实验三种变体。
4. 只使用目标生成工具实际支持的参数。不要杜撰镜头元数据或模型开关。
5. 生成后按九项框架复核；优先修正空间畸变、雨面逻辑、人物手脚、伪文字和全局过饱和。

### 制定修图方向

1. 先保护人物身份、品牌文字、建筑结构和真实事件，不把修图变成内容替换。
2. 分开处理曝光层次、局部颜色、反射与雨粒、建筑校正、主体引导和输出锐化。
3. 允许颜色偏离肉眼记录，但保持光源—反射—表面之间的因果关系；皮肤与中性物体不要被全局青红调色污染。
4. 用相对关系描述调色，例如“压低环境亮度，让红橙反射成为次级高光”，不要声称存在固定数值配方。

## 交付质量门槛

- 让地点具体到街道结构、建筑用途或城市物件，不只写“东京霓虹街”。
- 让雨至少改变两类表面，例如路面、玻璃、伞、金属、标牌或衣料。
- 保持一个清晰视觉主语；信息密集不等于无层级。
- 说明为什么选择标准、广角、长焦或鱼眼视角，以及它对空间叙事的作用。
- 让人物承担尺度、孤独、偶然、身份或动作中的至少一种功能。
- 同时保留近未来感与城市记忆，不用随机霓虹、过度辉光和橙青滤镜代替叙事。
- 对事实、观察和推断保持可追溯性；无法确认时明确说出。

## 禁止误用

- 不把全部作品归类为“赛博朋克”，也不把《银翼杀手》《AKIRA》《攻壳机动队》的影响误写成复制目标。
- 不把暴雨、裸机拍摄或高速快门当作必要条件；清晰倒影常需要更平静的水面。
- 不把环境人物误写成以棚拍、夸张时装姿态或浅景深为唯一中心。
- 不下载、打包或再分发摄影师作品作为 Skill 资产；只保存研究结论和公开来源链接。
- 不暗示本 Skill 获得摄影师授权、代表摄影师本人，或能复刻其作品与官方后期流程。
