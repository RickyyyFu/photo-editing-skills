# Roberta Mazzone 摄影与修图指导

基于意大利摄影师 Roberta Mazzone（Instagram：[_lagiuditta](https://www.instagram.com/_lagiuditta/)）公开作品与采访整理的独立摄影 Skill。

它将观察到的视觉特点转化为摄影规划、照片分析、修图方向和图像生成提示词：自然光、建筑框景、安静的生活片段、克制暖色、深色阴影与真实材质。

**本 Skill 非官方，与摄影师无隶属关系，未获得其授权。** 这里提供的是公开作品的风格分析与创作指导，不是摄影师的官方预设或精确复刻工具。

## 能做什么

| 需求 | 使用方式 | 输出 |
| --- | --- | --- |
| 修已有照片 | 上传照片，指定 `edit` | 在可用图像编辑工具中执行修改，并说明调整 |
| 只要调色建议 | 上传照片，要求不执行编辑 | Lightroom / Camera Raw 调整方案 |
| 分析照片 | 上传照片，指定 `critique` | 优点、主要问题、裁剪与调色建议 |
| 生成新图片 | 指定 `generate` | 提示词；有图像生成工具时可生成图片 |
| 准备实拍 | 指定 `shoot` | 光线、选景、服装、人物动作、镜头与拍摄清单 |
| 做一组故事 | 指定 `story-sequence` | 连贯的多张照片规划与色彩方向 |

Skill 本身是指导文件，不是修图软件；实际编辑或生成需要当前环境提供相应工具。

## 快速开始：修一张照片

1. 在 Codex 对话中上传自己的原照片，尽量使用高质量文件。
2. 复制下面的指令。
3. 看结果后，用一句具体要求继续调整，例如“减少暖色，保留上一版的阴影”。

```text
$roberta-mazzone-photography

用 edit 模式修我上传的照片，强度中等偏轻。
先根据原图判断适合的调整，再直接输出修图结果。

允许调整：曝光、白平衡、色彩、局部明暗、轻微颗粒。
保持原始画幅；裁剪和透视修改先给建议。

保留人物身份、五官、体型、姿势、服装、建筑结构及主要物体。
不新增、删除或移动人物和物体。

视觉方向：
保护天空、浅色衣物和皮肤高光；保留有深度的阴影。
轻微增加暖色，降低杂乱颜色的饱和度，让肤色和白色保持自然。
保留木材、石头、布料和皮肤的真实质感。
避免塑料皮肤、HDR、重度橙青滤镜、假光束、粗颗粒和重度暗角。

完成后说明主要修改，检查人物、结构和材质是否出现变化。
```

图像编辑可能重新绘制细节，不能保证逐像素保留。如果照片用于需要严格真实性的交付，建议使用下一节的参数指导，并在传统修图软件中操作。

## 只要 Lightroom / Camera Raw 调色方案

适合希望保留原始照片内容、自己控制修图过程的情况。

```text
$roberta-mazzone-photography

分析我上传的照片，先不要修改或生成图片。
给我适用于 Lightroom / Camera Raw 的修图方案：

- 裁剪和垂直线建议
- 曝光、白平衡、高光、阴影、白色色阶、黑色色阶
- 曲线
- HSL
- 色彩分级
- 局部蒙版
- 纹理、清晰度、锐化、颗粒

根据这张照片给出参数起点、调整理由和观察目标。
区分 JPEG 与 RAW 的参数限制，不要把建议称为摄影师的官方预设。
```

参数是针对上传照片的建议起点，不是适用于所有照片的固定配方。仅凭预览图无法精确判断 RAW 的恢复空间。

## 先分析照片

```text
$roberta-mazzone-photography

用 critique 模式分析这张照片，暂时不执行修图。
告诉我已经做得好的地方、三个最值得改善的问题，
以及具体的裁剪、明暗、颜色和质感建议。
保留这张照片本来的时间、天气和地点感。
```

## 生成新图片

```text
$roberta-mazzone-photography

用 generate 模式生成一张原创竖幅旅行摄影图片。
场景：深秋海边客舍，一位成年人安静地放下茶杯。
强调自然侧光、门窗框景、人物与环境的关系、
克制暖色、冷色海面和真实布料、木材、石头质感。
比例 4:5，无文字和标识。
请先将风格分析转化为描述性的视觉要求，再生成图片。
```

最终生成提示词使用具体的光线、构图、色彩与材质描述，不使用摄影师姓名作为风格标签。

## 制定实拍方案

```text
$roberta-mazzone-photography

用 shoot 模式为一家海边民宿制定两小时拍摄方案。
人数：一位成年模特；器材：相机与一支标准变焦镜头。
输出选景、光线时间、服装、人物动作、12张拍摄清单和后期方向。
优先拍日常动作与生活痕迹，并安排阴天备选方案。
```

## 连续修一组照片

```text
$roberta-mazzone-photography

分析我上传的这组照片，为它们制定统一后期方向。
统一白平衡倾向、黑位深度、饱和度和颗粒强度，
同时保留每张照片真实的天气与光线差异。
先选一张作为色彩基准，再说明其他照片应如何匹配。
```

## 怎么让指令更有效

给出以下信息会更容易得到合适结果：

- **用途**：旅行记录、社交平台、民宿宣传、印刷或作品集。
- **修改强度**：轻微、中等或明显。
- **允许范围**：只调色，或允许裁剪、透视及指定物体清理。
- **必须保留**：人物身份、姿势、场景结构、文字或产品颜色。
- **输出需求**：修改后的图片、操作建议，或两者都要。
- **文件信息**：JPEG / RAW、拍摄条件，以及已做过的调整。

修图后可以继续说：

```text
沿用上一版，暖色减少一点，海面恢复自然冷蓝。
保持人物和构图，仅调整色彩。
```

## 常见问题

**需要每次写很长的指令吗？**  
不需要。上传照片后写“用 $roberta-mazzone-photography 轻微调色，保留人物和场景”也可以。第一次说明修改边界会更准确。

**任何照片都能修成这种感觉吗？**  
效果取决于原图的光线、构图与内容。Skill 会优先保留现场特点；强烈闪光、杂乱构图等问题可能需要重拍才能改善。

**这是一个滤镜或预设文件吗？**  
不是。它根据照片制定调整方向，目前不包含摄影师官方 LUT、XMP 或 Lightroom 预设。

**能保证人物和建筑完全不变吗？**  
AI 图像编辑存在细节变化的可能。需要严格保留内容时，使用参数指导，在 Lightroom / Camera Raw 等软件中完成调整。
